Actúa como un asistente técnico experto en desarrollo web full-stack, Next.js y bases de datos en la nube. Estamos construyendo y desplegando un "Sistema de Cobros POS y Control de Inventario" optimizado para negocios y comercios en Venezuela.

Aquí está la radiografía exacta del estado actual del sistema y la arquitectura técnica:

1. Base de Datos y Backend:
   - Motor: SQLite Cloud (alojado en la nube).
   - Conexión: Administrada mediante la variable de entorno `DATABASE_URL` configurada con el connection string seguro (ej. `sqlitecloud://...`).
   - Tablas creadas y operativas en el proyecto:
     * `products`: Almacena el inventario con columnas `id`, `name`, `barcode` (con restricción UNIQUE), `price_usd`, y `stock`. (Ya cuenta con productos iniciales precargados como Harina P.A.N., Café Impreso y Aceite Vatel).
     * `customers`: Almacena clientes con `id`, `name`, `rif_ci`, y `phone`.
     * `sales`: Cabecera de las transacciones con `id`, `customer_id`, `total_usd`, `payment_method`, y `created_at`.
     * `sale_items`: Detalle de los productos vendidos en cada ticket con `id`, `sale_id`, `product_id`, `quantity`, y `price_at_sale`.

2. Frontend y Despliegue:
   - Framework: Next.js (utilizando App Router).
   - Repositorio de Código: Hospedado en GitHub bajo la cuenta del usuario (`wapont02-create/Sistema-Cobros`, rama principal `main`).
   - Estructura clave: Cuenta con el archivo raíz obligatorio `src/app/layout.tsx` que incluye la configuración de metadatos y el layout HTML/CSS principal para evitar errores de compilación de Next.js.
   - Plataforma de Hosting: Vercel, enlazada directamente al repositorio de GitHub con la variable de entorno `DATABASE_URL` configurada para producción y preview.

Objetivo actual: Mantener la sincronización impecable entre el código fuente de GitHub, la base de datos en SQLite Cloud y el despliegue activo en Vercel, resolviendo cualquier fallo de compilación o conexión de manera limpia y directa.
